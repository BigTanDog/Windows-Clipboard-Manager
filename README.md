# Windows Clipboard Manager

Windows 剪贴板历史工具：常驻托盘，按快捷键唤出面板，自动记录复制过的**文字 / 网址 / 图片 / 文件**，
随时搜索、收藏、再次粘贴。所有数据只存在本机，**不联网**。

- 系统：Windows 10 / 11（x64）
- 默认快捷键：`Ctrl + Shift + V`

## 快速上手

1. 双击运行，托盘出现剪贴板图标。
2. 随便复制点东西，再按 `Ctrl + Shift + V`——面板会从屏幕右下角弹出，刚复制的内容就在列表最上面。
3. 面板里的操作：
   - **单击** 选中一条，**双击** 或 **`Enter`** 粘贴它；
   - `↑↓` 选择、`Delete` 删除、**右键** 收藏 / 删除 / 粘贴、`Esc` 关闭面板；
   - 顶部搜索框可以按内容或文件名过滤。
4. 面板底部右侧有个 ⚙ 齿轮，点它直接进设置。

### 粘贴到别处

选中一条后按 `Enter`（或双击）：内容会回到剪贴板，并自动粘贴到你刚才复制的那个窗口里
（这个"自动粘贴"可以在设置里关掉，关掉后内容只回到剪贴板，自己按 `Ctrl + V`）。

## 它能做什么

- **四类内容都认得**：文字、网址（有单独标识）、图片（带缩略图）、文件（显示文件名），每类有自己的颜色标记。
- **搜索**：按内容或文件名即时过滤。
- **收藏**：常用内容右键收藏，收藏的条目永远不会被自动清理。
- **删除即吊销**：删掉一条记录时，如果系统剪贴板里装的**正是它**，剪贴板会一并清空 —— 桌面右键的「粘贴」立刻变灰，
  删掉的内容不会再被误粘贴出来。面板上带「**剪贴板中**」徽标的就是当前剪贴板里的那一条，可在设置里关掉这个联动。
- **自动清理**：可设置"最多保留多少条"和"最多占多少磁盘"，超了自动删最旧的（收藏的除外）；设置页能实时看到当前占了多少空间，一键打开缓存文件夹。
- **隐私保护**：手机号、银行卡、邮箱、密钥等在列表里**只显示前几位**（可在设置关闭）；只影响显示，粘贴出去的仍是完整原文。1Password、KeePass 等密码管理器复制的内容会自动跳过。
- **外观**：面板透明度可调、深浅色跟随系统、圆角界面、应用图标。
- **便携**：整个软件就一个 exe，数据写在它旁边的 `data` 文件夹里；换电脑把文件夹整体拷走即可。

## 设置项一览

| 设置 | 说明 |
| --- | --- |
| 记录条数上限 | 超出后自动删最旧的（50 / 100 / 200 / 500 / 不限制） |
| 磁盘占用上限 | 图片等缓存最多占多少（200MB / 500MB / 1GB / 2GB / 不限制） |
| 全局快捷键 | 唤出面板的组合键，默认 `Ctrl + Shift + V`；点一下输入框，**直接按下想用的组合键**即可（Esc 取消） |
| 粘贴后自动发送 Ctrl+V | 关掉后只复制到剪贴板，由你自己粘贴 |
| 敏感信息脱敏显示 | 手机号 / 账号等只显示前几位 |
| 删除记录时清空剪贴板 | 默认开启：只在该记录**正是当前剪贴板内容**时清空（随后桌面「粘贴」会变灰）；剪贴板里是别的内容时绝不动它 |
| 主题 | 跟随系统 / 浅色 / 深色（改动立即生效） |
| 点击面板外部时自动隐藏 | 默认开启；不喜欢可关掉 |
| 单击条目即粘贴并收起面板 | 默认关闭（单击只选中）；打开后恢复"点了就贴" |
| 面板透明度 | 0 = 不透明，数值越大越透（最高 35%，保证内容可读） |
| 按来源程序排除 | 指定程序里复制的内容不进历史 |
| 记录图片 | 截图 / 复制的图片是否入历史 |
| 开机自启 | 可设置延迟启动，避开开机高峰 |

## 数据保存在哪

全部在**程序自己的文件夹**里：`data\history.db`（记录）、`data\blobs\`（图片等本体）、`data\logs\app.log`（日志）。
不写 `%APPDATA%`，不写注册表（仅开机自启会用系统标准的自启项）。**想迁移/备份，把整个文件夹拷走就行。**

## 常见问题

**托盘图标不见了？**
Windows 默认会把新图标收进任务栏右下角的「隐藏的图标」，打开 ^ 把它拖到可见区即可。

**为什么没有毛玻璃 / 模糊效果？**
Windows 提供给第三方窗口的模糊接口在透明窗口上不够稳定（实测会出现内容显示异常），
为了保证面板始终能正常显示，当前版本采用**纯半透明**（最高 35% 透明度）而非系统模糊。

**粘贴密码管理器里的内容没有记录？**
这是刻意设计：密码管理器会声明"不要进剪贴板历史"，本工具尊重该声明。

**删了记录，为什么按 Win+V（剪贴板历史）还能找到？**
Windows 的剪贴板历史由系统自己保管，系统没有提供"按条目删除"的接口，任何第三方程序都删不掉其中的某一条。
本工具的「删除即吊销」清掉的是**系统当前剪贴板**（也就是右键「粘贴」能粘出来的那一份，删完立刻变灰）；
此外**已经粘贴到别处**的内容也无法收回。想彻底避免，可在系统设置里关掉「剪贴板历史记录」。

**历史记录是加密的吗？**
不是。数据以明文保存在本机 `data\` 里，脱敏只是"屏幕上不显示全"。请自行注意电脑的物理安全。

## 从源码构建

需要 .NET 8 SDK（含 Windows Desktop）。在仓库根目录：

```powershell
.\scripts\build.ps1      # 构建
.\scripts\test.ps1       # 跑测试
.\scripts\publish-fd.ps1 # 发布：小体积单文件（目标机需装 .NET 8 桌面运行时）
.\scripts\publish-sc.ps1 # 发布：免运行时单文件（体积较大）
```

产物在 `artifacts/` 下（`小体积-需装运行时` / `大体积-免运行时`）。
版本号集中在 `Directory.Build.props` 的 `<Version>`，设置窗口最下方会显示当前版本。
