# 开发者指南

> 本文档面向想构建、修改或参与本项目的开发者；普通用户请看根目录的 [README.md](../README.md)。
> 产品层面的决策记录见 [产品计划文档.md](产品计划文档.md)，实现细节见 [技术设计文档.md](技术设计文档.md)。

## 构建与测试

需要 .NET 8 SDK。脚本已封装 SDK 路径（本机装在 `D:\dotnet`，见 `scripts/_dotnet.ps1`）。

```powershell
.\scripts\build.ps1     # 构建解决方案（Debug）
.\scripts\test.ps1      # 运行全部测试（xUnit，当前 249 项）
```

> 若 PATH 里的 `dotnet` 指向没装 SDK 的目录（例如只有运行时的 `C:\Program Files\dotnet`），
> 会报 `No .NET SDKs were found`；脚本里统一用完整路径 `D:\dotnet\dotnet.exe`。

## 发布（双形态）

```powershell
.\scripts\publish-fd.ps1   # 形态 B：框架依赖单文件，需目标机装 .NET 8 Desktop Runtime
.\scripts\publish-sc.ps1   # 形态 A：自包含单文件，免运行时
```

产物目录名直接说明区别：

| 形态 | 产物目录 | 体积 | 适用 |
| --- | --- | --- | --- |
| B（默认） | `artifacts/小体积-需装运行时/ClipboardManager.exe` | **2.85 MB** | 目标机已装 .NET 8 Desktop Runtime |
| A | `artifacts/大体积-免运行时/ClipboardManager.exe` | **64.39 MB** | 免运行时、任意 Windows x64 |

对外分发的副本放在仓库 `release/` 目录（文件名面向用户），**每次更新版本后需要同步覆盖**。
注意二进制入 Git 会让仓库体积随版本增长，发版频繁时建议改用 GitHub Releases。

> 关于体积：最初需求期望「≤25MB」。WPF 的裁剪在 .NET SDK 中**已被禁用**（官方《Known trimming
> incompatibilities》），Native AOT 也不支持任何桌面 GUI 框架，因此「免运行时 + ≤25MB」在
> C#/.NET 桌面栈内不可兼得；若必须 ≤25MB，只能换 Avalonia+NativeAOT 或换语言/运行时。

## 应用图标

图标由 `src/ClipboardManager.App/Assets/app-icon-source.png`（方形源图）经脚本生成：

```powershell
.\scripts\make-icon.ps1 -Source src\ClipboardManager.App\Assets\app-icon-source.png
```

脚本会裁掉源图留白、缩放到 16/32/48/64/256 五个尺寸、把圆角方块外侧做成透明（避免深色任务栏上出现白色方角），
再组装成 `Assets\app.ico`。该 ICO 同时用于：exe 文件图标（`ApplicationIcon`）、窗口图标与托盘图标
（作为嵌入资源在运行时读取，缺失时回退到代码绘制的剪贴板图标）。

## 架构

```
src/
  ClipboardManager.Core/    纯逻辑：格式解析/生成（DIB、HTML Format、DROPFILES）、搜索片段、
                            脱敏、淘汰规划、主题解析、自启命令行、ICO 写出   ← 无 Win32、无 WPF，可单测
  ClipboardManager.Interop/ Win32 封装：隐藏消息窗口、剪贴板读写、热键、托盘、自启项、DWM 外观
  ClipboardManager.Storage/ SQLite 仓储（手写 SQL + 预编译语句）、blobs 本体存储（哈希分桶、原子写）
  ClipboardManager.App/     WPF：面板窗口、设置窗口、主题字典、托盘图标绘制、AppHost 编排
tests/ClipboardManager.Tests/  xUnit（284 项）
docs/  产品计划文档.md（决策基线 D-01~D-14 + 附加项清单）· 技术设计文档.md（TDD）
```

关键设计点：

- **STA 亲和**：剪贴板 API 有线程亲和性，读写在 STA 线程完成，跨线程只传已拷进托管内存的纯数据。
- **隐藏消息窗口**：接收剪贴板/热键/托盘回调。用 `WS_POPUP | WS_EX_TOOLWINDOW` 的**隐藏顶层窗口**
  而不是 `HWND_MESSAGE` —— 后者无法成为前台窗口，`TrackPopupMenuEx` 弹不出托盘菜单。
- **面板是逐像素透明窗口**（`AllowsTransparency`）：圆角、底色、阴影全由根卡片负责。
  ⚠️ 因此**不要**对它使用 `SetWindowCompositionAttribute` 的模糊/亚克力（accent 3/4）——
  实测在隐藏态反复设置或随时间推移都会破坏合成（内容只剩鬼影）；B-04 的"透明度"最终只改 WPF 底色 alpha
  （见 `Core/Ui/AcrylicTint`，上限 35%）。
- **托盘图标**：嵌入的 `Assets/app.ico` → 取图像 → `CreateIconFromResourceEx`（该 API 收的是
  「单个图像」，不是整份 .ico）→ `Shell_NotifyIconW`；处理 `TaskbarCreated` 重挂、退出时先 `NIM_DELETE` 再 `DestroyIcon`。
- **图片本体分离**：数据库只存摘要与哈希，本体写 `data/blobs/<前2位>/<哈希>.png`；缩略图 512px 长边。
- **淘汰先提交事务、后异步删文件**，避免长事务；收藏项不参与自动淘汰。
- **脱敏只在展示层**：`SensitiveMasker` 用 `NonBacktracking` 正则 + 超时（剪贴板输入不可信），
  银行卡需通过 Luhn 校验才脱敏以压误报。
- **菜单分隔线**要覆盖 `MenuItem.SeparatorStyleKey`，隐式 `Separator` 样式对菜单里的分隔线不生效。
- **删除即吊销（D-14）**：清剪贴板前必须确认"装的正是这条"——快速路径查 `ClipboardPresenceTracker`（序列号 ↔ 记录 id），
  兜底路径算 `ClipboardFingerprint`；清空走 `ClipboardAccess.TryClearIfSequence`，**复核与 `EmptyClipboard` 都在剪贴板锁内**，
  序列号变了就放弃。指纹口径必须与 `CaptureProcessor` 保持一致（有等价性回归测试），漂移会静默失效。
- **设置文件新增字段**：源生成反序列化对**缺失字段**给的是类型零值而非属性初始值 ——
  新增"默认开启"的开关必须升 `AppSettings.CurrentSchemaVersion` 并在 `Normalize()` 里按旧版本号补默认值（详见技术设计 §7.4）。

## 命令行参数

| 参数 | 作用 |
| --- | --- |
| `--diag` | 输出诊断日志（启动耗时、目录定位、托盘/主题/淘汰等 DIAG 行） |
| `--duration=N` | N 秒后自动退出（用于体积/内存/冷启动的自动化测量） |
| `--delay=N` | 延迟 N 秒再开始监听（开机自启时避开开机高峰） |
